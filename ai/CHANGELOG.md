# TMX AI Brief changelog

v1.0.0  2026-08-18  — First release. `tmx-brand/SKILL.md` is an Agent Skill an ambassador attaches to an AI chat before prompting: instructions written to the model, not documentation written for a human. It opens with three standing behaviours (ask before you make, never invent a brand value, say what you are doing before a first draft) and a closed four-question intake, capped so the model asks once instead of interviewing. The rule set is the site's own published ambassador rulebook carried over in the same order and wording, so the skill cannot drift from what ambassadors already agreed to at the generator's rules gate; rule 2's two approved sentences are marked reusable and are what the worked examples resolve to. AI-specific extensions cover every numbered rule in turn, not just "use the marks as supplied," since an AI can break each of them in ways a human holding a file or reciting a phrase cannot. The mark ban is scoped to the resulting image rather than the wording of the request and instructs the model to refuse the rephrase, because commercial logos are the least-refused category in text-to-image guardrails and a mark described without being named is refused almost never; the skill says so plainly so the model does not defer to its own filters. Images route to the card generator first. When the generator cannot produce a format the model may author SVG, HTML, or CSS that places the supplied mark unmodified and draws structure around it, using a bounded eight-value palette copied from both kits' `tokens.css` and no rendered copy at all in any of the three, since the point is keeping type out of the model's own hands, not just SVG's font-fallback bug. Seven worked good/bad pairs cover the failures that actually occur, weighted evenly across the two observed ones: hype voice and broken visuals. Brand values are otherwise not inlined; the skill links to the kits so it cannot fall out of sync with them. Staying loaded orders four ways to load the rules into a conversation: a pasted fetch line for a one-off chat, the same line saved once into a workspace's custom instructions or memory feature, an agent installing the file itself into wherever it keeps skills, and downloading and attaching the file only as the last resort, all without naming any AI product since paid tiers reprice constantly. It keeps that ordering distinct from the reload cadence, since instruction adherence degrades within a few exchanges regardless of how the file got loaded, and states plainly that an installed or downloaded copy is a cached copy that goes stale and must be re-fetched on the same cadence, not a way around that rule. Ships with `primer-prompt.txt` and `tools/check-ai-palette.ps1`.
