# TMX AI Brief changelog

v1.0.0  2026-08-18  — First release. `tmx-ai-brief.md` is the file an ambassador attaches to an AI chat before prompting: instructions written to the model rather than documentation written for a human. It opens with three standing behaviours (ask before you make, never invent a brand value, say what you are doing before a first draft) and a closed four-question intake, capped so the model asks once instead of interviewing. The rule set is the site's own published ambassador rulebook (`ambassadors.guide.*` on `/ambassadors`: never promise returns, say what TMX is, pair the name with its home, speak as community, use the marks as supplied) carried over in the same order and wording, so the brief cannot drift from what ambassadors already agreed to at the generator's rules gate; rule 2's two approved sentences are marked as reusable copy and are what the worked examples resolve to. Four AI-specific rules extend it, since an AI can break "use the marks as supplied" in ways a human holding a file cannot: never generate a mark, never generate anything mistakable for a real TMX artifact, never invent a brand value, ™ never ®. The mark ban is scoped to the resulting image rather than to the wording of the request, and instructs the model to refuse the rephrase, because commercial logos are the least-refused category in text-to-image guardrails and a mark described without being named is refused almost never; the brief says so plainly so the model does not defer to its own filters. Images route to the card generator first, quoting what the generator does and does not check, so the model understands its half of the job is the words. Six worked good/bad pairs cover the failures that actually occur (hype voice, invented metric, fake endorsement, AI-generated mark, missing domain pairing, em dashes and crypto idiom), since exemplars outperform rules for voice. Brand values are deliberately not inlined: the brief links to the kits rather than restating hexes and type, so it cannot fall out of sync with them and does not hand a model what it needs to hand-build a mark. A per-platform block covers staying loaded (Gemini Gems are free-tier, Custom GPTs need Plus, Claude Projects need Pro, everyone else re-uploads) plus a reload cadence, because instruction adherence measurably degrades within a few exchanges. Memory guidance stores a version-stamped pointer to this file, never the rules themselves, so a cached copy cannot silently go stale after a version bump. Ships with `primer-prompt.txt`, the copy-paste block that names the brief as authoritative and carries the generator, hub, and kit links.
