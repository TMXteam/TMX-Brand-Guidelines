# TMX AI Brief changelog

v1.0.0  2026-08-18  — First release. `tmx-brand/SKILL.md` is an Agent Skill an ambassador attaches to an AI chat before prompting: instructions written to the model, not documentation written for a human. It opens with three standing behaviours (ask before you make, never invent a brand value, say what you are doing before a first draft) and a closed four-question intake, capped so the model asks once instead of interviewing. The rule set is the site's own published ambassador rulebook carried over in the same order and wording, so the skill cannot drift from what ambassadors already agreed to at the generator's rules gate; rule 2's two approved sentences are marked reusable and are what the worked examples resolve to. Four AI-specific rules extend it, since an AI can break "use the marks as supplied" in ways a human holding a file cannot. The mark ban is scoped to the resulting image rather than the wording of the request and instructs the model to refuse the rephrase, because commercial logos are the least-refused category in text-to-image guardrails and a mark described without being named is refused almost never; the skill says so plainly so the model does not defer to its own filters. Images route to the card generator first. When the generator cannot produce a format the model may author SVG that places the supplied mark unmodified and draws structure around it, using a bounded eight-value palette copied from both kits' `tokens.css` and no brand typography, since unembedded SVG text falls back to Arial and Georgia everywhere except the machine that authored it. Seven worked good/bad pairs cover the failures that actually occur, weighted evenly across the two observed ones: hype voice and broken visuals. Brand values are otherwise not inlined; the skill links to the kits so it cannot fall out of sync with them. A per-platform block covers staying loaded plus a reload cadence, because instruction adherence degrades within a few exchanges. Memory guidance stores a version-stamped pointer, never the rules. Ships with `primer-prompt.txt` and `tools/check-ai-palette.ps1`.
